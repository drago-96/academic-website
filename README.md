# zanot.to

Source of my personal website, [zanot.to](https://zanot.to), built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme.

## Local preview

```bash
docker compose up -d
```

The site is then served at <http://localhost:8080>.
